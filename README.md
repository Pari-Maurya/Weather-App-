# 🌦️ Weather App

A simple weather application built using **React**, **Vite**, **Material UI**, and the **OpenWeatherMap API**.

## Features

* Search weather by city name
* View current temperature
* Check humidity and feels-like temperature
* Display weather conditions
* Responsive UI with Material UI

## Tech Stack

* React
* Vite
* JavaScript
* Material UI
* OpenWeatherMap API

## Installation

```bash
npm install
npm run dev
```

## API Used

OpenWeatherMap API

```text
https://api.openweathermap.org/data/2.5/weather
```
